# 변수와 타입

> 💡 **핵심**: 변수는 메모리 번지에 붙여진 이름이다
> 타입을 선언하고, 값을 대입하고, 활용한다. 이 세 단계가 변수의 전부다.

---

## 🧠 변수란 무엇인가?

### 메모리와 변수의 관계

```
RAM (메모리)
┌──────────────────────────────┐
│  번지 0x001   │  번지 0x002    │
│    age = 25  │  score = 90   │
└──────────────────────────────┘
       ↑               ↑
   변수 이름        변수 이름
   (메모리 번지에 붙인 별명)
```

**변수(Variable)** = 하나의 값을 저장할 수 있는 메모리 번지에 붙여진 이름

---

## 📌 변수 선언 3단계

### 1단계: 선언 (타입 + 이름 결정)

```java
int age;       // 정수(int) 값을 저장할 age 변수
double value;  // 실수(double) 값을 저장할 value 변수
```

> ⚠️ 이 시점에서는 메모리 할당 X. 이름만 결정한 상태.

### 2단계: 초기화 (최초 값 대입 → 메모리 할당)

```java
int score;   // 선언만 된 상태 (메모리 할당 X)
score = 90;  // 최초 값 대입 → 이 순간 메모리 할당 O
```

### 3단계: 선언 + 초기화 동시에 (권장)

```java
int score = 90;  // 선언과 동시에 초기화
```

---

## 🔤 변수 이름 규칙

| 규칙                                   | 예시                                |
| -------------------------------------- | ----------------------------------- |
| **첫 글자는 반드시 문자**              | `age` ✅ / `1age` ❌                |
| **중간부터 문자, 숫자, `$`, `_` 허용** | `my_score`, `value1` ✅             |
| **소문자로 시작**                      | `score` ✅ / `Score` ❌             |
| **여러 단어는 캐멀 스타일**            | `totalMinute` ✅ / `totalminute` ❌ |

> 🐪 **캐멀(Camel) 스타일**: 낙타 등처럼 단어 경계마다 대문자  
> `myVariableName`, `totalScore`, `getUserAge`

---

## ⚠️ 초기화하지 않으면 컴파일 에러

### ❌ 잘못된 코드

```java
int value;                // 선언만 함 (초기화 X)
int result = value + 10;  // 컴파일 에러!
// The local variable value may not have been initialized
```

**이유**: 초기화되지 않은 변수는 메모리에 할당되지 않아 값을 읽을 수 없다.

### ✅ 올바른 코드

```java
int value = 30;            // 초기화 O
int result = value + 10;   // value(30) + 10 = 40
```

## 🚀 변수 활용 예제

### 연산 및 출력

```java
public class VariableUseExample {
    public static void main(String[] args) {
        int hour = 3;
        int minute = 5;

        System.out.println(hour + "시간 " + minute + "분");

        int totalMinute = (hour * 60) + minute;
        System.out.println("총 " + totalMinute + "분");
    }
}
```

```
// 실행 결과
3시간 5분
총 185분
```

### 변수 간 값 복사

```java
int x = 10;
int y = x;  // x의 값(10)을 y에 복사

// x = 10, y = 10 (독립적으로 저장됨)
```

> 📌 **핵심**: 복사 후 x를 변경해도 y는 영향받지 않는다. 각자 독립된 메모리 공간을 가진다.

### 두 변수의 값 교환

```java
public class VariableExchangeExample {
    public static void main(String[] args) {
        int x = 3;
        int y = 5;
        System.out.println("교환 전 → x:" + x + ", y:" + y);

        int temp = x;  // x 값을 temp에 임시 보관
        x = y;         // y 값을 x에 대입
        y = temp;      // temp(원래 x) 값을 y에 대입

        System.out.println("교환 후 → x:" + x + ", y:" + y);
    }
}
```

```
// 실행 결과
교환 전 → x:3, y:5
교환 후 → x:5, y:3
```

**교환 과정 시각화**:

```
초기 상태:   x = 3,    y = 5,    temp = ?
1단계:       x = 3,    y = 5,    temp = 3   (temp = x)
2단계:       x = 5,    y = 5,    temp = 3   (x = y)
3단계:       x = 5,    y = 3,    temp = 3   (y = temp)
```

> 💡 두 변수의 값을 직접 교환하면 한쪽 값이 덮어써진다. **반드시 임시 변수(temp)가 필요하다.**

---

## 📋 핵심 요약

```
1. 변수 선언    →  타입과 이름 결정 (메모리 할당 X)
2. 초기화       →  최초 값 대입 시 메모리 할당
3. 선언 + 초기화 동시 권장  →  int score = 90;
4. 초기화 없이 사용  →  컴파일 에러 발생
5. 값 교환  →  임시 변수(temp) 필수
```

**변수 이름 관례**:

```
소문자 시작 + 캐멀 스타일
✅ totalScore, myAge, getUserName
❌ TotalScore, my_age, getusernam
```
