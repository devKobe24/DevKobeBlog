# 🧠 기억력 외 기억법 — 같은 노력으로 2배의 효과를 내는 사전 준비 전략

> **핵심 원칙 :** 기억력을 개선하지 않아도 된다. '사전 준비'를 제대로 갖추면 같은 노력으로 2~3배의 효과를 낼 수 있다.

---

## 📋 기억의 4단계 — 순서를 지켜야 작동한다

```
이해  →  정리  →  기억  →  반복
```

이 순서를 건너뛰고 바로 '기억'으로 뛰어드는 것이 **통째암기**다.  
통째암기는 시간이 걸리고, 금세 잊어버리며, 기억력이 나쁜 사람일수록 더 자주 쓴다는 아이러니가 있다.

---

## 1️⃣ 통째암기 금지 — '이해'와 '정리'가 먼저다

| 방법                | 기억 유형     | 결과                          |
| ------------------- | ------------- | ----------------------------- |
| 통째암기            | 의미 기억     | 외우기 어렵고 금세 잊음       |
| 이해 → 정리 후 암기 | 에피소드 기억 | 자연스럽게 기억되고 오래 남음 |

이해하고 정리하는 데 충분한 시간을 들이면  
'의미 기억'이 '에피소드 기억'으로 변해 암기 부담이 크게 줄어든다.

> 💡 기억력이 부족하다고 느낄수록 '이해'에 더 집중해야 한다.

---

## 2️⃣ 높은산 기억법 — 전체에서 세부로

### 핵심 원리

기억에서 가장 중요한 것은 **관련성**이다.  
전체 구조를 먼저 파악하면 각각의 세부 내용이 어디에 속하는지 알게 되고, 관련성이 강해져 기억에 잘 남는다.

```
❌ 처음부터 순서대로  →  관련성 약함  →  기억에 남기 어려움
✅ 전체 파악 → 세부 읽기  →  관련성 강함  →  기억이 오래 남음
```

직소 퍼즐로 비유하면, 틀(전체 구조)이 잡히면 조각(세부 내용)을 어디에 놓을지 바로 판단할 수 있다.

### 책 읽기에 적용하는 법

```
① 목차 훑기       → 전체 구조 파악
② 띄엄띄엄 읽기   → 흥미로운 부분, 핵심 위치 파악 (5분)
③ 처음부터 정독   → 이미 틀이 잡혀 있어 내용이 쉽게 흡수됨
```

> 💡 예습이 효과적인 이유도 같다. 그날 배울 내용의 전체상을 미리 잡아두기 때문이다.

---

## 3️⃣ 대책강좌 기억법 — 전체상을 단시간에 파악하라

어떤 분야의 공부를 시작할 때 가장 먼저 할 일은 **전체상 파악**이다.

- 혼자 교재를 처음부터 읽으면 전체 파악에 긴 시간이 걸린다
- 기초강좌·대책강좌를 활용하면 **3시간에 200쪽 분량의 전체상과 핵심**을 잡을 수 있다

시험 합격 여부의 90%는 암기력이나 머리가 아니라 **사전 준비**에서 결정된다.

---

## 4️⃣ 정리노트 기억법 — 논리적 정리가 기억을 40% 높인다

뇌과학 연구(존 메디나, <브레인 룰스>)에 따르면

> _"논리적으로 정리되고 계층적으로 제시된 정보는 임의로 제시된 것보다 기억될 확률이 40% 더 높다."_

```
보기 좋은 노트  →  시각 이미지로 흡수  →  암기 부담 감소
너저분한 노트   →  읽기도 싫어짐       →  암기 전에 의욕 상실
```

정리는 이해를 요구하고, 정리를 통해 이해가 더 깊어지는 선순환이 생긴다.  
**남에게 설명할 수 있을 정도로 정리되었다면, 따로 암기하지 않아도 대부분 기억으로 정착된다.**

---

## 5️⃣ 기출문제 기억법 — 시험의 20%가 80%를 결정한다

### 기출문제를 쓰는 올바른 방법

```
❌ 기출문제를 통째로 암기한다
✅ 기출문제로 '출제자의 의도'와 '출제 경향'을 분석한다
```

**실전 활용법**

```
① 기출문제를 먼저 쭉 훑어본다 (풀지 못해도 무관)
② 각 문제가 교재의 어느 부분에 해당하는지 형광펜으로 표시
③ 여러 해 반복하면 '자주 나오는 부분'과 '거의 안 나오는 부분'이 보임
④ 나만의 '마법의 교과서'가 완성됨
```

### 파레토 법칙 (20:80 법칙)

| 구분                    | 비율     | 전략             |
| ----------------------- | -------- | ---------------- |
| 시험에 자주 나오는 핵심 | 상위 20% | 먼저, 집중적으로 |
| 가끔 나오는 나머지      | 80%      | 여유가 있을 때   |

> 상위 20%를 완전히 암기하면 80점 수준의 점수가 가능하다.  
> 첫 페이지부터 균등하게 공부하는 것은 가장 비효율적인 방법이다.

---

## 6️⃣ 단어장 기억법 — 100% 암기의 비밀

### 단어장 만들기

기출문제를 분석한 후 외워야 할 것들을 **일대일 조합**으로 카드에 정리한다.

```
앞면  :  스코틀랜드 국화
뒷면  :  엉겅퀴
```

> 💡 선택지에 등장한 다른 항목도 함께 정리하면 유사 문제까지 대비할 수 있다.

### 레벨 나누기 — 외운 카드에 시간을 낭비하지 마라

```
전체 카드
  ├── ✅ 암기 끝   → 시험 직전 최종 확인용
  ├── 🔄 암기 중   → 맞힐 때까지 반복
  └── ❌ 어려운 문제 → 집중 공략 대상
```

**핵심 요령 :** 이미 외운 카드를 반복하는 것은 시간 낭비다.  
'어려운 문제' 카드 전부를 맞힐 수 있을 때 **100% 암기**가 완성된다.

---

## 📌 사전 준비 기억법 요약

| 기억법                 | 핵심 행동               | 효과                           |
| ---------------------- | ----------------------- | ------------------------------ |
| **통째암기 금지**      | 이해 → 정리 순서 지키기 | 의미 기억 → 에피소드 기억 전환 |
| **높은산 기억법**      | 전체 파악 후 세부 읽기  | 관련성 강화 → 기억 지속        |
| **대책강좌 활용**      | 전체상을 단시간에 파악  | 공부 시작점 설정               |
| **정리노트**           | 계층적으로 논리 정리    | 기억 확률 40% 향상             |
| **기출문제 분석**      | 출제 경향·의도 파악     | 중요한 20% 선별                |
| **단어장 + 레벨 분류** | 모르는 카드에만 집중    | 100% 암기 달성                 |
