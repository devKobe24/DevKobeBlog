# 🌐 인터네트워킹 — 네트워크와 네트워크를 연결하다

> **핵심 개념 :** 인터네트워킹(Internetworking)은 독립적인 네트워크들을 연결하여 데이터를 중개하는 것이다. 인터넷은 전 세계 네트워크가 라우터로 연결된 거대한 인터네트워킹 시스템이다.

---

## 1️⃣ 인터네트워킹이란?

```
네트워크 A ←→ 인터네트워킹 시스템 ←→ 네트워크 B
```

**인터네트워킹 = 네트워크 + 네트워크 연결**

- 물리적 연결 + 논리적 연결 (프로토콜 지원)
- 데이터 경로 선택 및 중개
- 라우터 같은 중개 장비 사용

---

## 2️⃣ 네트워크 연결 구조

<img src="https://github.com/devKobe24/images2/blob/main/internetworking.png?raw=true"/>

```
                네트워크 2
                    ↕
네트워크 1 ←→ 인터네트워킹 시스템 ←→ 네트워크 3
```

### 주요 기능 — 경로 선택

네트워크 1에서 들어온 데이터를 **네트워크 2로 보낼지, 네트워크 3으로 보낼지** 결정해야 한다.

> 💡 **도로 비유 :** 삼거리에서 자동차 내비게이션이 경로를 선택하는 것과 유사하다.

### 지원 범위 — OSI 7계층 중 하위 3계층

```
네트워크 계층 (Layer 3)  ← 경로 선택
데이터 링크 계층 (Layer 2)
물리 계층 (Layer 1)
```

---

## 3️⃣ 게이트웨이 — 인터네트워킹을 실제로 수행하는 장비

게이트웨이(Gateway)는 지원하는 계층에 따라 3가지로 구분된다.

| 종류 | 지원 계층 | 주요 기능 | 예시 |
|------|-----------|-----------|------|
| **리피터<br>(Repeater)** | 물리 계층 (L1) | 신호 증폭 | 신호 증폭기 |
| **브리지<br>(Bridge)** | 물리 + 데이터 링크 (L1~L2) | 신호 증폭 + 오류 처리 | 무선 공유기 |
| **라우터<br>(Router)** | 물리 + 데이터 링크 + 네트워크 (L1~L3) | 신호 증폭 + 오류 처리 + 경로 선택 | 인터넷 라우터 |

---

## 4️⃣ 게이트웨이 상세 설명

### 리피터 (Repeater) — 신호 증폭

```
약해진 신호 ──→ [리피터] ──→ 증폭된 신호
```

- **역할 :** 거리가 멀어져 약해진 신호를 증폭
- **계층 :** 물리 계층 (L1)
- **한계 :** 오류는 처리하지 못함

> 📡 사람 목소리도 멀리 갈수록 작아지는 것처럼, 전기/무선 신호도 감쇄된다.

---

### 브리지 (Bridge) — 신호 증폭 + 오류 처리

```
신호 + 오류 ──→ [브리지] ──→ 증폭 + 오류 수정
```

- **역할 :** 리피터 기능 + 물리 계층 오류 해결
- **계층 :** 물리 + 데이터 링크 (L1~L2)
- **예시 :** 가정용 무선 공유기

---

### 라우터 (Router) — 경로 선택의 핵심

```
데이터 입력 ──→ [라우터] ──→ 경로 판단 ──→ 최적 경로로 전송
                    ↓
              라우팅 테이블
```

- **역할 :** 경로 선택 + 오류 처리 + 신호 증폭
- **계층 :** 물리 + 데이터 링크 + 네트워크 (L1~L3)
- **핵심 기능 :** 
  - 연결된 네트워크/호스트 정보 관리
  - 경로 가용성 판단
  - 최적 경로 선택

> 💾 **라우팅 테이블 :** 네트워크와 호스트 정보를 저장하여 경로 선택 시 사용

---

## 5️⃣ 인터네트워킹 시스템의 역할

### 필수 조건

```
✅ 물리적 인터페이스 지원 (각 네트워크에 맞는 하드웨어 연결)
✅ 논리적 인터페이스 지원 (각 네트워크의 프로토콜 지원)
✅ 프로토콜 변환 (필요 시 데이터 형식 변환)
```

### 연결 가능성

- 서로 다른 종류의 네트워크도 연결 가능
- 프로토콜이 다르면 변환 작업 수행
- 모든 연결된 네트워크와 개별 연동

---

## 📌 핵심 요약

```
인터네트워킹  =  네트워크 + 네트워크 연결
인터넷        =  전 세계 네트워크의 인터네트워킹 시스템
게이트웨이    =  인터네트워킹을 수행하는 실제 장비

리피터  →  신호 증폭 (L1)
브리지  →  신호 증폭 + 오류 처리 (L1~L2)
라우터  →  신호 증폭 + 오류 처리 + 경로 선택 (L1~L3) ⭐
```

| 개념 | 설명 |
|------|------|
| **인터네트워킹** | 독립 네트워크들을 연결하여 데이터 중개 |
| **게이트웨이** | 인터네트워킹 기능을 수행하는 장비 |
| **라우팅 테이블** | 경로 선택을 위한 네트워크/호스트 정보 저장소 |
| **OSI 하위 3계층** | 물리(L1) + 데이터링크(L2) + 네트워크(L3) |
