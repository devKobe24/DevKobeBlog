# 🌐 네트워크 기초 핵심 정리

> 복잡한 네트워크 용어와 개념을 쉽고 명확하게 이해하기

## 📝 들어가며

현대의 인터넷은 작은 조직의 네트워크들이 서로 연결되며 발전했습니다. 하지만 **TCP**, **IP**, **HTTP** 같은 약어들이 난무하면서 개념을 이해하기 어려워졌죠.

### ⚠️ 용어 이해 시 주의사항

기존 단어의 의미로 새로운 기술 용어를 이해하려는 **선입견을 버려야** 합니다. 네트워크 용어는 기존 단어를 재활용하지만, 원래 의미와 다른 경우가 많습니다.

---

## 🔑 핵심 용어 6가지

### 1️⃣ 시스템 (System)

**정의:** 내부 규칙에 따라 자율적으로 동작하는 대상

**특징:**

- 물리적 대상: 컴퓨터, 라우터, 스마트폰 등
- 소프트웨어 대상: 운영체제, 프로세스 등
- 네트워크 환경에서는 **데이터 교환 기능 필수**

**핵심:** 작은 시스템들이 모여 더 큰 시스템을 구성할 수 있습니다.

---

### 2️⃣ 인터페이스 (Interface)

**정의:** 시스템과 시스템을 연결하기 위한 표준화된 접촉 지점

**두 가지 관점:**

#### 🔧 하드웨어 관점

- **물리적 규격:** 잭의 크기와 모양
- **논리적 규격:** RS-232C, USB 등의 데이터 교환 규격
- **예시:** 컴퓨터와 키보드 연결

#### 💻 소프트웨어 관점

- **함수 인터페이스:** 함수명, 매개변수 표준화
- **계층 모델:** 상하 계층 간의 연결 규칙

**핵심:** 양방향 데이터 교환 또는 단방향 데이터 전송으로 구분됩니다.

---

### 3️⃣ 전송 매체 (Transmission Media)

**정의:** 데이터를 물리적으로 전달하는 수단

**종류:**

- 📡 유선: 동축 케이블, 광섬유 등
- 📶 무선: WiFi, 5G 등의 무선 신호
- 🌊 기타: 공기(소리 전파) 등

**관계:**

```
인터페이스 (논리적 규격) → 전송 매체를 통해 구현 → 데이터 전송
```

---

### 4️⃣ 프로토콜 (Protocol)

**정의:** 시스템 간 데이터 교환을 위한 표준화된 통신 규칙

**핵심 개념:**

- **동등한 관계:** 상하 관계가 아닌 같은 계층의 시스템 간 규칙
- **데이터 형식:** 주고받는 데이터의 구조 정의
- **절차:** 통신 과정의 순서 정의

**인터페이스 vs 프로토콜:**
| 구분 | 인터페이스 | 프로토콜 |
|------|-----------|---------|
| 관계 | 상하 계층 간 | 동등 계층 간 |
| 초점 | 접촉 지점 | 통신 규칙 |

---

### 5️⃣ 네트워크 (Network)

**정의:** 전송 매체로 연결된 여러 시스템이 프로토콜을 사용해 데이터를 주고받는 단위

**구성 요소:**

```
시스템 ↔ [인터페이스] ↔ 전송 매체 ↔ [인터페이스] ↔ 시스템
         └─────────── 프로토콜 ───────────┘
```

**확장성:**

- 소규모 네트워크들이 모여 더 큰 네트워크 구성
- 네트워크 간 연결: **라우터(Router)** 사용

---

### 6️⃣ 인터넷 (Internet)

**정의:** 전 세계 모든 네트워크가 유기적으로 연결된 통합 네트워크

**핵심 특징:**

- 공통 프로토콜: **IP (Internet Protocol)** 사용
- OSI 7계층 모델의 3계층(네트워크 계층) 담당
- Internet Protocol의 첫 단어에서 명칭 유래

**구조:**

```
작은 네트워크 → 중규모 네트워크 → 인터넷 (거대 연합체)
```

---

## 🎯 표준화 (Standardization)

**정의:** 서로 다른 시스템의 상호 연동을 위한 형식 통일

**필요성:**

```java
// 표준화가 없다면?
프린터_A → 전용_용지_A  // 호환 불가
프린터_B → 전용_용지_B

// 표준화 적용 후
프린터_A → A4_규격  // 자유로운 조합
프린터_B → A4_규격
```

**적용 영역:**

- 🔌 하드웨어: 물리적 규격 통일
- 📋 소프트웨어: 데이터 형식 및 절차 통일
- 🌐 네트워크: 프로토콜 표준화 (TCP/IP)

---

## 💡 핵심 요약

| 용어       | 한 줄 정의               | 관점        |
| ---------- | ------------------------ | ----------- |
| 시스템     | 자율적으로 동작하는 대상 | 주체        |
| 인터페이스 | 시스템 간 접촉 지점      | 연결점      |
| 전송 매체  | 물리적 전달 수단         | 매개체      |
| 프로토콜   | 통신 규칙                | 규칙        |
| 네트워크   | 시스템의 연결 단위       | 집합        |
| 인터넷     | 전 세계 네트워크 통합체  | 최상위 집합 |

---

## 🚀 4차 산업혁명과 표준화

현대 산업사회의 발전은 **표준화 원리**를 바탕으로 한 **레고의 조합 개념**이 핵심입니다.

```
증기기관 → 에너지 혁명 → 산업혁명
표준화 → 상호 연동 → 인공지능 시대
```

서로 다른 부품들이 표준화된 규격으로 자유롭게 결합되면서, 무한한 확장과 발전이 가능해졌습니다.

---

## 📌 마무리

네트워크의 6가지 핵심 개념을 이해하면 복잡한 인터넷 구조도 명확하게 파악할 수 있습니다. 각 용어는 독립적이면서도 유기적으로 연결되어 있으니, 전체적인 관계를 이해하는 것이 중요합니다! 🎓
